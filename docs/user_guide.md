# Руководство оператора

Приложение открывается в браузере (Chrome/Edge/Firefox — любой современный). Три вкладки: **Дела**, **Источники**, **Настройки**.

## 1. Первый запуск

1. Откройте вкладку **Настройки** → раздел «Слоты документов». По умолчанию четыре слота: Справка, ЕГРП, Платёжное поручение, Прочее.
2. При необходимости добавьте свои слоты, поправьте маски (подстрока в имени файла или `/regex/`), задайте порядок перетаскиванием `≡`.
3. Проверьте раздел «Парсинг Справки» — синонимы лейблов, по которым из xlsx-справки извлекаются ЛС / период / поставщик / услуга / дата. Дополните под свой шаблон.
4. Проверьте раздел «Подвал» — включён ли, какой цвет и размер.
5. Проверьте «Титульный лист дела» — включён ли.

## 2. Добавление папок

Есть два способа:

### 2.1. Загрузить папку из своего компьютера (основной)

Вкладка **Источники → «Загрузить папку»**.

- **Название** — что показывать в списке.
- **Папка** — кнопка «Обзор» открывает системный диалог; выберите папку, браузер отправит **всё её содержимое** (включая подпапки) на сервер.

После загрузки автоматически запускается сканирование. Прогресс отображается под формой (проценты и мегабайты).

Работает в Chrome, Edge, Firefox. Все файлы сохраняются в отдельный volume на сервере (`/data/uploads/src_<id>/`), при удалении источника файлы удаляются с диска.

### 2.2. Bind-mount (админ-режим)

Разворачивается в разделе «Или добавить существующую bind-mount папку». Требует, чтобы папка была заранее смонтирована в контейнер (см. [deployment.md](deployment.md)).

- **Название**
- **Путь внутри контейнера** — должен начинаться с одного из разрешённых корней (указаны под формой), например `/data/demo`.

Этот режим удобен для больших постоянных источников (сетевые шары, регулярно обновляемые папки) — read-only, файлы не копируются на сервер.

## 3. Сканирование

Кнопка **↻ Сканировать** сверху справа — сканирует все зарегистрированные источники. У каждого источника есть свой **↻ Пересканировать**.

После скана появляется diff-панель: сколько файлов обработано, сколько новых дел, сколько обновилось.

Сканирование — идемпотентно и безопасно: статусы «напечатано» и «передано в суд» сохраняются, файлы просто перестраиваются заново.

## 4. Работа с делами

### Список

Вкладка **Дела**. Столбцы: КСР, Лицевой счёт, За период, Услуга, Поставщик, Комплектность, Напечатано, В суде, Действия.

### Поиск и фильтры

- **Поиск** — по КСР или ЛС (подстрока).
- **Комплектность** — Все / Полные / Неполные.
- **Печать** — Все / Напечатаны / Не напечатаны.
- **Передача в суд** — Все / Переданы / Не переданы.
- **Услуга**, **Поставщик** — dropdown автоматически заполняется по имеющимся значениям.

Кнопка **Сбросить** очищает все фильтры.

### Сортировка

Кликните на заголовок столбца **КСР**, **Напечатано** или **В суде** — сортирует по возрастанию/убыванию.

### Карточка дела

Клик по строке (не по чекбоксу и не по иконкам действий) — открывает боковую панель:

- Метаданные из Справки
- Состав дела: слоты по порядку, файлы в каждом. Отсутствующий обязательный слот — красная плашка. Дубликаты (несколько файлов в одном слоте) — оранжевая пометка.
- История печатей — все даты, когда дело печаталось.
- Кнопки: **Удалить дело**, **Отметить переданным**, **Печать**.

Закрыть карточку: `Esc`, крестик, клик по затемнению.

### Одиночная печать

- Из строки: иконка 🖨.
- Из карточки: кнопка «🖨 Печать».

Откроется новая вкладка с готовым PDF, браузер автоматически предложит диалог печати (или нажмите Ctrl+P). Дата «Напечатано» проставится автоматически, в историю добавится запись.

### Пакетная печать

1. Отметьте чекбоксами нужные дела (или чекбокс в шапке — выделить всё).
2. Внизу появится тёмная плашка с массовыми действиями.
3. Нажмите **🖨 Печать выбранных**.

Все выбранные дела собираются на сервере в **один PDF** и открываются в одной вкладке. Диалог печати — **один на весь пакет** (Ctrl+P).

Порядок в PDF: дела идут подряд в том порядке, что в таблице. Каждое дело начинается собственным титульным листом. Подвал `КСР/NN` нумеруется **в рамках каждого дела** (сброс на каждом новом деле) — так сшивальщик может собрать страницы в блоки, если пачка перемешается на выходе принтера.

### Отметить переданными

- Одно дело: «📅 Отметить переданным» в карточке. Дата = сегодня. Повторный клик — снимает статус.
- Пачка: чекбоксами → «✓ Отметить переданными» в bulk-баре.

### Снять статусы

Пачка → **↺ Снять статусы** — сбрасывает «Напечатано» и «Передано в суд» у выбранных дел. История печатей сохраняется.

### Удалить

- Одно дело: «🗑 Удалить дело» в карточке или иконка 🗑 в строке.
- Пачка: **🗑 Удалить** в bulk-баре.

Удаляется только запись в базе. Файлы в папках-источниках **не тронутся**. При следующем сканировании дело появится снова, но с чистыми статусами — это удобный способ пересобрать одно дело с нуля.

## 5. Работа с неполными делами

Дело считается **неполным**, если не хватает файла хотя бы в одном **обязательном** слоте (см. настройки).

Неполное дело — с красной/оранжевой пометкой. В карточке видно, каких файлов не хватает. Печать неполного дела возможна, но требует подтверждения.

Чтобы дополнить — положите нужный файл в папку-источник (имя должно содержать КСР) и запустите пересканирование.

## 6. Дубликаты

Если два файла попадают в один и тот же слот (например, два разных «Платёжных поручения» под один КСР) — в карточке видно «2 файла». При печати оба попадут в PDF последовательно (сортировка по имени). Чтобы оставить один — удалите лишний из папки-источника и пересканируйте.

## 7. Настройки — тонкая подстройка

### Слоты

Настраиваются под ваш workflow. Порядок = порядок листов в готовом PDF и очерёдность в лотке.

Маска — подстрока (case-insensitive) или регулярное выражение вида `/regex/`. Примеры:

- `Выписка ЕГРП` — файлы с этой подстрокой в имени.
- `/Платежн\w+ поручение/` — Платёжное или Платежное (без ё).

Флаг **Обязательный** — определяет, будет ли дело «неполным» без этого слота.

Слот **Прочее** — служебный, всегда последний, ловит всё, что не подошло другим слотам. Можно выключить чтобы игнорировать «мусор».

### Лейблы Справки

Синонимы, по которым в xlsx ищутся значения. Синонимы через запятую. Значение = соседняя справа ячейка (или после `:` в той же ячейке).

Если у вас нестандартный шаблон Справки — добавьте свои варианты лейблов.

### Подвал и титульный лист

Тумблеры в разделах «Подвал каждой страницы» и «Титульный лист дела». Подвал — светло-серым в самом низу каждой страницы, формат `КСР/номер_листа`.

### Backup

- **Экспорт JSON** — скачивает файл с настройками, слотами, лейблами и всем реестром дел (кроме файлов — они читаются из папок).
- **Импорт JSON** — восстанавливает состояние. Заменяет настройки и реестр; список папок сохраняется.
- **Очистить дела** — удаляет только реестр (настройки/папки/лейблы сохраняются). Для пересбора с нуля.
- **Очистить всё** — полный сброс к дефолтам.

## 8. Быстрые клавиши

- `Esc` — закрыть карточку дела.
- `Ctrl+P` — печать открытой PDF-вкладки.
